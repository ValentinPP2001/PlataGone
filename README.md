# PlataGone
Backend de **PlataGone**, una aplicación para gestionar gastos y finanzas personales. Permite registrar compras, tickets y comprobantes, organizar gastos y productos por categorías, mantener un historial de movimientos, gestionar tarjetas y créditos, y generar resúmenes financieros para descubrir, finalmente, dónde se fue la plata. 💸
